# AlI

当前创作流程与功能边界见 [统一游戏素材创作](docs/UNIFIED_GENERATION.md)。填写需求→生成下方可编辑提示词→单独点击生产，游戏CG采用逐次续接；模型与素材不随仓库分发。

Windows 本地游戏素材创作工具，Python + PySide6 独立界面。AlI（AIImages）是显示名称，仓库与Python包保留兼容。

顶部为「游戏CG / 精灵图 / 音频」，精灵图下选择单张或动画帧。左侧显示成品与播放／导出，右侧为「参考 / 生成」，底部任务只显示名称、进度与耗时。位置固定、宽度可调，启动默认打开参考页。

## 当前生成路线

- **游戏CG**：每次生成一段，完成后填写新的要求再接续，不默认自动排五段。新作品2–8秒，后续每段2–7秒，使用原生22帧上下文；累计32秒已实测。前段原生画面保留，不重复采样。初版CG输出无声画面。源视频人物／画风编辑仍为8秒以内试用，精确手势和Q版比例存在偏差。
- **音频**：同一个需求框，自动识别或手选BGM／游戏音效。ACE-Step负责10–180秒器乐配乐；Woosh负责0.5–5秒音效，未将其当成已验证的BGM替代品。支持波形、播放／定位、WAV导出和缓存清理。Woosh只安装必要文字生音效组件，未安装视频配音／评分模型。
- **文字生图**：无参考默认Z-Image Turbo，支持人物、物件、场景、画风与视角。有参考默认FLUX.2 Klein；手选引擎不被暗中替换。图片实际使用Qwen文本编码器不代表使用Qwen Image。
- **图片编辑**：1–4张稳定编号图，直接写“图1主体保留，仅换成图2画风”等要求。语言助手不再逐图识别／重述外貌；实际原图独立送入生成引擎，缺图引用拒绝提交。
- **精灵动画**：MiniMax H3生成完整片段，或按真实视频／GIF／自然排序PNG帧做参考编辑。默认使用参考原时长、不自动循环；更改时长提示可能降低对应精度。没有普通动作分析按钮、文字时间轴或隐藏旧动作表。旧Wan和骨骼生成入口不恢复。
- **素材导出**：先预览完整动画，再自主选帧导出精灵PNG＋JSON或独立PNG；不默认拆帧，不自动挑选关键帧。先生成RGB再按需要处理透明背景，不混帧。
- **用户自带API**：单图支持OpenAI Images兼容及Gemini原生接口；Key由用户提供，不读取其他软件凭据。[说明](docs/API_GENERATION.md)。

LoRA已停用，不自动选择或下载。语言助手仅专业化文字并在生成前退出，原文保留；素材导入不会启动识别。新模型下载完不等于验证通过。Vibe Motion骨骼适配已做小样：确定性渲染通过，人物替换后仍有节奏／手位偏差，初版继续原参考动画路线，不加新的识别依赖。[比较与边界](docs/VIBE_MOTION_EVALUATION.md)。

## 使用

1. 运行`run.bat`。单图连接自己的本机ComfyUI，H3与独立音频使用已验证的私有进程，不要求用户手动打开或编辑特定工作流。
2. 选择创作类别，把图片、视频／GIF或PNG帧文件夹拖入画布／参考区域。参考预览、播放和移除不会替换左侧成品。
3. 在「生成」页填写「用户需求」，必要时调整片长、参考起点或循环。点击「生成提示词」后在下方查看／修改，再单独点击「生成图片」等生产按钮。图片逐张独立识别，提示词用具体内容代替图片编号，不做多图联合视觉分析。输入或素材变化不会套用旧稿。中文输入保持可见，图片提交尽量使用忠实英文；不完整转换保留完整中文，不发送残缺译文。
4. CG完成后填写下一段要求并点接续生成；想另做一部时点新建视频。图片、音乐与音效在各自结果区查看、试听或另存。
5. 动画需要素材帧时再点选帧与导出。需要去背景时选择透明导出，默认没有预选帧。

种子默认随机，本次实际值可查看、复制与复用，结果和导出保留真实值。随机不保证最佳。软件不显示普通debug面板；详细失败原因可点击失败任务查看。

结果先存本地缓存，长期保留需主动另存／导出。「记录」中可清理对应类别缓存，正在处理的任务受保护；外部另存文件保留。历史Wan／骨骼成品仍可读取，但不能提交旧生成路线。

## 像素素材与后处理

独立CLI：`python -m sprite_pipeline --help`，支持snap、normalize、palette、assemble、validate、config及run。像素捕捉→统一画布/锚点→共享调色板→精灵图→验收，输出可逐像素切片回读的metadata。[配置与验收](docs/SPRITE_PIPELINE.md)。

不使用时间混合、FXAA/TAA/DLSS或全局自动抗锯齿。像素预览用最近邻，不默认缩放角色。透明处理只改Alpha，保留原生RGB。PNG支持完整透明；GIF二值透明有限制。当前原生生图默认不开额外超分。

## 安装、模型和稳定性

桌面依赖见`requirements-lock.txt`，`setup.bat`创建独立Python3.13环境。复用自己的ComfyUI，不覆盖原工作流。H3有独立安装/验收步骤，见[动画说明](docs/VIDEO_FIRST.md)。模型、参考图、生成记录、环境和Key均不上传Git。

FLUX可选组件安装：`python -m tools.prepare_flux_klein --comfy-root "YOUR_COMFY_ROOT"`，复用已有且SHA一致的Qwen3编码器，只新增扩散模型与VAE。需实际生成验收后才注册，不能手工把文件存在等同于验证。[模型比较与来源](docs/MODEL_SELECTION.md)。

管理Wan权重只按安装收据、大小和发布SHA逐文件删除。本轮按用户要求退役核验一致的SDXL主模型，硬链接去重后释放约14.04GB；原ControlNet、IP-Adapter、姿态检测、CLIP Vision、图片和工作流保留。旧SDXL检查点/Wan/骨骼安装器不再安装这些退役权重。

进度连接中断时按原任务标识继续查询，不自动重复提交；Windows短暂占用进度文件时重试原子保存。H3取消/关闭只处理自己的进程树，不重启共享后端。其他程序正在使用GPU时，实际速度会变化。

用户的排除要求直接写在需求中；FLUX.2没有独立反向条件，软件不再展示正反提示词框。生成仍可能有手部、服装、视角或身份细节偏差。有限测试通过不代表百分之百准确。H3和其他模型的许可各自有效；游戏资产使用/分发前需核对模型原始条款。
