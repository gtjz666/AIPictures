# 统一游戏素材创作流程

顶部是游戏 CG、精灵图、音频。精灵图包含单张和动画帧。右侧参考页管理图片与动画；生成页上方填写用户需求，点击「生成提示词」，下方直接显示可编辑提示词，确认后再点击「生成图片／动画／音频／本段」。两步独立，整理提示词不会提交生产。参考预览不会覆盖左侧成品，重新启动默认显示参考页。

## 需求如何进入模型

用户原文是唯一的创作要求。原文不会被整理结果替换；任务同时保存原文、实际提交稿、素材编号与签名。修改文字、参考素材、时长或续接来源后旧稿失效，处理中修改或取消不会提交旧结果。等待本次任务完成后再开始下一次。

图片提示词使用逐张独立观察：每次视觉请求只含一张图片，识别可见主体、外形、姿势和画法；随后用纯文字按用户要求挑选相关信息。不把多张图片一起送入视觉模型，不自动分析动画。下方成稿直接说明具体内容，不再用「图1、图2、参考图」代称；仍有指代的结果会被拒绝，原稿保留。原图片仍逐张独立送入生成引擎，图片不会被文字描述替代；编号只用于素材管理、用户需求和内部对应，删除一张不会重编号。缺图引用会阻止提交。

例如“将图1的人物美术风格修改为图2的风格，保留图1动作与外形”，成稿应写明主体的实际外形、原动作以及目标画法，仅借用第二张图片的渲染方式，不将其人物身份写入主体描述。手动编辑下方提示词后，以编辑稿生产；需要英文时仅翻译当前文字，不重新读图或专业化。需求、素材或参数变化后，旧稿不能直接生成，须重新整理或明确修改下方提示词。图片实际使用 FLUX.2 Klein；Qwen 是文本编码器／语言助手，不代表正在使用 Qwen Image。FLUX.2 没有独立负向条件，不再把旧自动反词拼入新要求。

官方依据：[FLUX.2 不支持 negative prompting](https://help.bfl.ai/articles/7734566352-does-flux-2-support-negative-prompting)、[Qwen Image Edit 2511 的直接编辑示例](https://huggingface.co/Qwen/Qwen-Image-Edit-2511)。后者不代表所有 Qwen 模型都没有反向条件；该候选仍未在本机启用。

需要复制参考姿势并更换主体时，单张模式现有「姿势／结构来源」：实际深度条件提供姿势与布局，语言助手只整理主体外观和明确修改，不猜肢体文字。当前支持一张结构图＋一张主体图，人形低蹲和一个非人形卡通样例已实测；手部、鞋形和比例仍可能偏离。见[结构参考说明](STRUCTURE_REFERENCE.md)。只换画风仍沿用独立流程，动画／CG不套用这条尚未验证时序的静态路线。

## 精灵动画

直接将真实参考动画／自然排序的 PNG 帧送入专用 Ref2VA。普通界面不再展示动作分析或时间轴，不让错误的动作文字盖过素材。默认采用参考原时长；改变时长会提示可能降低对应精度。导入不自动循环，不把不足两秒的参考强行延长到两秒。

当前源编辑仍受已验证的单段 8 秒范围限制；较长源保留原时长，但要求选择范围内片段。1–4张编号图可指定人物、画风等用途。动作迁移仍可能简化手势或改变身体比例，不承诺逐帧换皮。没有参考动画时，用户描述的动作及顺序完整保留，不附加“以参考视频为准”的虚构条件。

先生成完整动画，再由用户在导出时选帧；不自动拆帧。播放器关闭／选帧窗关闭后不继续错误保护已完成缓存。清除缓存保留另存的文件。

## 游戏 CG 逐次续接

每次点击生产按钮只生成一段。新作品为2–8秒，后续每段2–7秒；这是为原生22帧历史上下文预留空间，不是将整部作品限制在7秒。完成后填写下一段要求、生成并检查提示词，再点击接续生成。前段已经交付的画面逐像素保留，不重采样；累计成片可超过30秒。不再默认一次排五段。

续接使用前段原生上下文，不将单张末帧重绘称作完整历史。新任务冻结之前的视频、RGB和清单签名，保留失败尝试；不会覆盖或自动重试。新建视频清除续接来源。初版 CG 导出无声画面，独立音频由音频类别制作。无源动画时目前只支持一张初始参考图，多图可先在单张模式合成。

## 独立音频

自动按需求选择用途，也可手选背景配乐或游戏音效。BGM 使用既有 ACE-Step，10–180秒；Woosh 专注游戏音效，0.5–5秒，48kHz单声道。Woosh不作为经过验证的BGM作曲替代品，未同时安装其视频配音／评分模型。

文字助手对BGM整理配器、节奏与结构，对音效保留声源、事件次数、先后顺序和衰减。音效不套用配乐的持续能量检查，不把自然留白误作失败。超出Woosh文字窗口会报错，不能截掉用户后半段要求。模型运行串行，结束即退出私有进程。

音乐阶段保留专业稿作为实际DiT文字条件，不再让内部规划器的二次描述覆盖；音频使用FP32解码，按可用资源选择设备，保存潜变量供核对。这是数值与指令一致性改进，不保证消除所有模型音色瑕疵。试听后再决定是否导出。
