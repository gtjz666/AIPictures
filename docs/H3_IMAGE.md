# H3 图片：原生多参考图编辑

按 [ComfyUI 官方说明](https://docs.comfy.org/tutorials/image/minimax/minimax-h3-image)与 [MiniMax 模型卡](https://huggingface.co/MiniMaxAI/MiniMax-H3-Image)接入本地 H3 Image。使用原生 MiniMaxH3ImageConditioning、图片 DiT 与图片 VAE，6步、CFG=1、Euler/Simple、denoise=1。没有额外负向采样、骨骼输入或属性权重图。

## 使用

在精灵图的单张模式添加参考图，进入「生成」填写要求，点击「生成提示词」查看和修改，再点击「生成图片」。语言助手只保留、整理或翻译原始要求，不另行识图、解释图片关系或补写全图外观。原始中文、实际英文、参考图与种子保存在任务中。

H3支持0–16张参考图；编号最小的一张是编辑基础。直接描述保留和修改的属性，例如保留某图的主体，仅采用另一图的画风。编号在删除后不变化，提交时一次性映射到实际输入的 `<Picture 1>` 等标签。缺图引用会报错，所有保留的图片分别进入视觉与参考潜变量条件，不拼贴，不丢弃额外图。16张已做界面与输入绑定检查；真实GPU验收的数量另见本机记录，不能将16张绑定检查当作16张满负荷生成验证。

自动路线在已注册H3时，有参考图使用H3，无参考仍用现有Z-Image；也可以手选H3做文字生图。显式选择不自动降级其他模型。H3独立启动与退出，不要求手动打开共享ComfyUI工作流。原有FLUX可显式选择；旧结构适配选项只属于旧路线，不会混入H3。

默认约400万像素，参考图编辑保留基础图比例。可以调整32倍数宽高；本地接口允许约100万–2000万像素，不表示本机已验证所有尺寸。模型官方16MP能力不等于12GB显存笔记本所有输入组合都稳定。RGB图片输出不自带Alpha；动画的透明帧仍在导出时由已有后处理产生，普通预览和原始RGB不覆盖。

## 本地设置与验收

复用已经安装的H3 Image图片权重、图片VAE和H3 Qwen3-VL编码器，不下载额外提示词扩写模型。独立环境和固定源码配置沿用 `tools.setup_h3_image_probe` 的安装收据。已有安装不应因名称含probe而重复下载。

`tools.verify_h3_image_live` 在隔离数据目录实际点击Qt两个按钮，验证文字生图、双图编辑、输入SHA、输出画幅、各阶段完成及进程退出。使用预先冻结的JSON计划；已有任务不自动重复提交，失败结果保留。`tools.register_h3_image` 只接受这些完成记录，核对模型、实际图数及官方采样参数后写本机 `data/h3-image-settings.json`。权重首次分块SHA校验，之后仅在路径、大小与文件时间均不变时复用记录；改动则重新校验。

编码、采样、解码依次运行，阶段间用校验过的张量包保存条件，释放前一阶段进程。取消和关闭只结束本次自有Windows进程树；不重启或中断共享ComfyUI。有其他共享任务运行时拒绝并行启动。生成目录保存三个实际workflow、任务标识、进程退出记录与原始输出。

## 效果边界

原生多图编辑避免了“先猜图片内容，再靠长提示词重建”的信息损失，但不是像素锁定的换脸工具。极端姿态、跨体型、手部接触、表情与角色细节仍可能偏离。之前7张已知素材研究有失败，不能用官方功能列表宣称普遍精准。本轮接入结果及质量观察以本机验收记录为准；不针对人物、物种、颜色、文件名或特定动作写分支。
