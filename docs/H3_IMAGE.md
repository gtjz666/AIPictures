# H3 图片：原生多参考图编辑

按 [ComfyUI 官方说明](https://docs.comfy.org/tutorials/image/minimax/minimax-h3-image)与 [MiniMax 模型卡](https://huggingface.co/MiniMaxAI/MiniMax-H3-Image)接入本地 H3 Image。使用原生 MiniMaxH3ImageConditioning、图片 DiT 与图片 VAE，6步、CFG=1、Euler/Simple、denoise=1。没有额外负向采样、骨骼输入或属性权重图。

## 使用

在精灵图的单张模式添加参考图，进入「生成」填写需求，再点击「生成图片」。例如「把图2人物的动作和表情改成图1的」。只需给出编辑对象、来源和用途，系统组织修改项与保留项，并把原文作为优先要求。可点击「查看参考分工」确认提交前的图号对应和画幅。见[手写流程说明](MANUAL_PROMPTS.md)。

H3支持0–16张参考图。系统识别明确的编辑目标时，将这张图放在模型的首个输入，原界面图号保持不变。复杂需求也可用「底图：图2」明确指定。缺图引用或指代不明时，会在开始推理前提示明确图号和用途。界面编号在提交时映射为 `<Picture 1>` 等标签，所有参考仍分别进入原生视觉与参考潜变量条件。16张已做界面与输入绑定检查。

本机安装并启用参考读图组件后，明确指定来源的编辑分开读取底图和来源图。底图提取该保留的辨识特征，来源图只读取指定的动作、表情、画风等。H3 仍会直接接收两张原图。读图结果与实际使用的提示词保存在任务的 `reference-guide/result.json` 和 `encode/workflow.json`。装有组件时依次运行并释放各阶段，用户仍在同一个输入框提交需求。

自动路线在已注册H3时，有参考图使用H3，无参考仍用现有Z-Image；也可以手选H3做文字生图。显式选择不自动降级其他模型。H3独立启动与退出，不要求手动打开共享ComfyUI工作流。原有FLUX可显式选择；旧结构适配选项只属于旧路线，不会混入H3。

默认约400万像素。识别出的编辑底图与当前自动画幅对应的图不同时，默认画幅随编辑底图调整。已另行指定的宽高继续使用本次填写值。可以调整32倍数宽高，本地接口允许约100万–2000万像素。动画的透明帧仍在导出时进行处理。

## 本地设置与验收

生成复用本地 H3 Image 图片权重、图片 VAE 和 H3 Qwen3-VL 编码器。参考读图组件使用独立配置 `data/h3-reference-guide-settings.json`，沿用已有 llama.cpp 运行库。旧的 8B 提示词助手与本组件独立。

`tools.verify_h3_image_live` 在隔离数据目录实际点击Qt两个按钮，验证文字生图、双图编辑、输入SHA、输出画幅、各阶段完成及进程退出。使用预先冻结的JSON计划；已有任务不自动重复提交，失败结果保留。`tools.register_h3_image` 只接受这些完成记录，核对模型、实际图数及官方采样参数后写本机 `data/h3-image-settings.json`。权重首次分块SHA校验，之后仅在路径、大小与文件时间均不变时复用记录；改动则重新校验。

编码、采样、解码依次运行，阶段间用校验过的张量包保存条件，释放前一阶段进程。取消和关闭只结束本次自有Windows进程树；不重启或中断共享ComfyUI。有其他共享任务运行时拒绝并行启动。生成目录保存三个实际workflow、任务标识、进程退出记录与原始输出。

## 显存记录与解码

编码、采样、解码各会话在任务目录写 `vram.json`。`cuda_free_bytes` 是设备当前真正空闲的显存（Comfy 的 `vram_free` 还包含 PyTorch 可回收缓存，已扣除）；`torch_active_bytes` 是实际分配的显存；`torch_reserved_bytes` 是分配器保留量；`torch_reusable_cache_bytes` 是保留但可回收的缓存。`native` 与 `cudaMallocAsync` 两种分配器都按同一公式记录。这些是每个阶段图运行前后的快照，不是采样峰值；不能把保留量当作已用显存，也不能把快照当作峰值诊断。

在12 GiB设备上，采样进程退出后改用 `--cpu` 的私有会话解码已保存的latent，避免第二个完整图片VAE峰值；大于12 GiB的设备仍用GPU解码，设备总量无法确认时也按CPU保守处理。CPU解码只影响解码设备，不改变采样、提示词、参考图或输出像素尺寸。读取失败时保留原任务和已完成阶段，不自动重试或覆盖。

## 效果边界

原生多图编辑避免了“先猜图片内容，再靠长提示词重建”的信息损失，但不是像素锁定的换脸工具。极端姿态、跨体型、手部接触、表情与角色细节仍可能偏离。之前7张已知素材研究有失败，不能用官方功能列表宣称普遍精准。本轮接入结果及质量观察以本机验收记录为准；不针对人物、物种、颜色、文件名或特定动作写分支。
