# 参考动作优先与手动动作表（2026-11-07）

此前逐段动作识别会有误差，即使从实际请求中过滤自动行，显示在提示词框中的动作文字仍会造成误解。现在取消动画内容分析与分析按钮，下方直接提供空白动作表；动作只由实际参考素材提供，用户可选填自己的修改要求。

## 本次实际改变

- 真实视频、GIF或PNG序列继续作为Ref2VA的独立视频输入，角色图作为独立图片输入。生成提示词明确：动作顺序、节奏、停顿、重复手势、幅度、方向、表情和镜头以实际视频为准。图像的静态站姿不限制动画，取消参考路线的固定全身/固定镜头要求。
- 动画页始终显示空白表格。只有用户填写的开始、结束和动作才同步提示词，支持增加/删除时段；不完整、越界、重叠、倒序或非有限时间阻止入队。时间为绝对成片秒数，不随时长自动缩放；参考起点、循环和用途变化不清空手填内容，不需重新分析。
- 用户直接改写正向提示词时，保留可见文字；删除或替换的时间线不能在后台重新出现。无动作参考时，原来的文字动画和时间线逻辑保留。
- 「自动生成提示词」只读取参考图和用户需求，不解码或观察动画。schema要求timeline为空，非空旧结果也被清除，不会填入手动表。点击按钮前有效的手填时段在整理后恢复；生成期间未完成的表格编辑同样令旧结果失效。反向词不凭空排除参考停顿、重复、转身或近景，用户排除词原文保留。
- 右侧选择的参考图用途在入队时冻结到任务：人物/外观、仅风格或自定义用法。风格参考不强制复制图片人物，自定义不默认锁定身份或站姿，缺少用法文字时阻止入队。
- 用途选择和浅蓝「自动生成提示词」按钮在正向标题右侧同排。动画分析原本共用Qwen3-VL-8B与视觉投影；因为参考图用途/外观识别还在使用，没有删除共用权重，也没有独立动作识别权重可删除。

`job.json`中的`user_prompt`保留界面原文，`prompt`为实际要求；`motion_timeline`仅含手填段落，不再写入`motion_analysis_timeline`，`motion_prompt_policy=reference_first_manual_v2`标记本规则。`prompt.txt`与`workflow.json`保存实际进入编码节点的完整提示词。旧任务及历史研究工具不批量改写，不恢复普通界面的动画分析入口。

## 模型接口与限制

本机安装的官方`MiniMaxH3ReferenceToVideo`使用`<Picture 1>`与`<Video 1>`引用分别输入的图像和视频，保留视频VAE及文本编码两个条件路径。[官方节点实现](https://github.com/Comfy-Org/ComfyUI/blob/master/comfy_extras/nodes_minimax_h3.py)与本机源码已核对，本次未更换节点、模型、采样参数或精度。

“最高优先级”是对模型的语义说明，没有冒充一个可调的数值权重或硬约束。它能去掉已确认的文字冲突，不能保证逐帧复刻、解剖结构之间无损转移或复杂手势识别准确。不要把程序测试通过称为真实生成画质改善已经验证。

本次没有新的GPU推理、生成或压力测试，没有下载/删除模型或依赖。界面与队列验证不代替相同素材、种子和设置的真实成片质量比较；手填时间线也不能作为模型已精确执行时刻的证明。
