# Godot外置生成窗口与角色组件

首版使用**单一手写提示词**。在Godot选择生成类型，打开AlI独立窗口，生成并预览；不自动分析多种需求，也不拆分提示词。Godot是4.x原生编辑器插件，已在本机4.6验证。

## 安装与打开

当前模块、端口和默认值见[模块手册](GODOT_BLUEPRINT_CATALOG.md)。场景蓝图提供动画串并行、UI、地图、相机和设置存档模块，可在基础场景里按需添加。

点「新建基础场景…」同时建立空白场景和空白画布。打开该场景时，它的蓝图自动加载。普通 Godot 场景可从「场景蓝图」打开。基础场景和游戏模块的素材更换步骤见[图解教程](GODOT_SCENE_BLUEPRINT_GUIDE.md)。

1. 在AlI顶部「Godot → 连接项目／安装插件」选择包含`project.godot`的文件夹。
2. 在Godot「项目 → 项目设置 → 插件」启用「AlI游戏素材」。右侧出现「AlI素材」面板，项目根目录自动准备角色底图`art/dino`、环境图片`art/world`、界面图片`art/ui`、声音`audio`和组件`generated/ali_assets`目录。插件会补齐缺少的目录并保留已有素材。
3. 选择图片、动画、音效或BGM，点击「打开生成窗口」。插件会传入当前项目路径；提示词在软件中自行填写。

也可将发行的`AlI-Godot-addon.zip`解压到项目，保留`addons/ali_assets`目录结构，再启用插件、选择AlI软件目录。需要软件已配置自己的运行环境和已验证生成模型；插件不包含权重，不会向聊天服务发送提示词。

## 导出与拖入

- **动画**在播放器选帧后点「导出动画…」，保存包含 PNG 与播放信息的 ZIP。「透明背景」只在确认导出后作用于选中的帧。
- 在 Godot 选中「通用动画」模块，把 ZIP 或现有图片帧拖到下方的动画轴。可调整帧顺序、时长、帧率、速度、循环和方向，然后点「应用动画轴」。
- **图片和音频**可另存为标准文件。将它们加入项目后，从 Godot 文件系统拖到对应的资源槽。也可从 AlI 的「Godot」菜单导出组件，并用「打开导出位置」找到它。
- 修改完成后点「应用到场景」，再保存 Godot 场景。

资源写入当前项目的`generated/ali_assets/名称_唯一编号`，包含实际PNG／音频、场景、可选控制脚本和来源说明。相同名称创建新版本，不覆盖旧组件或原素材。场景内部使用`res://`路径，运行时不依赖AlI或插件。

## 动作与角色蓝图

新角色和其他 2D 对象统一在「场景蓝图」编辑。下方的组件预设及[角色蓝图数据格式](GODOT_BLUEPRINTS.md)供已有项目维护。

动画动作包含待机、行走、奔跑、跳跃、攻击、受击、死亡、冲刺、翻滚、防御、施法、交互、攀爬、下落、落地。选择「动画素材」可直接指定当前动画所属动作。角色包可通过「关联其他动作帧文件夹」继续加入已生成／已有PNG序列。帧按文件名自然排序，同一角色各动画画布须一致。

用途预设：

| 预设 | 导出行为 |
| --- | --- |
| 图片节点 | Sprite2D，可直接放进场景 |
| 动画素材 | AnimatedSprite2D，播放所选动作 |
| 双向角色 | CharacterBody2D，左右镜像，平面移动 |
| 四向角色 | 分别播放上／下／左／右动画，平面移动 |
| 平台角色 | 重力、落地、跳跃、左右移动，支持奔跑与攻击动画 |
| 音效节点 | AudioStreamPlayer2D，留给游戏逻辑主动触发 |

四向必须提供四段真实不同方向的行走素材：可在当前选帧中分别指定范围，或关联各方向行走帧文件夹。不会把一段单向动画复制成四个方向。其他动作也可按方向关联；缺少奔跑动画时仅加速行走，缺少攻击动画时只发攻击信号，不自动生成新的动画。

旧组件默认WASD移动、Shift奔跑、Space跳跃、J攻击。可在检查器使用 `use_project_actions` 接项目 InputMap。新场景可通过按键、InputMap 和通用动画模块自行安排动作。

平台跳跃需要关卡地面碰撞体。`attack_requested`、`jump_requested`、`damaged`、`died`提供逻辑接口，`play_action()`可播放已关联动作；`take_damage()`和`die()`触发受击／死亡状态。生命值、攻击判定、敌人AI和技能效果由项目逻辑实现，不把一段攻击动画宣称为完整战斗系统。冲刺、施法等附加动作目前提供动画槽与播放接口，需由游戏逻辑调用。

角色可手动关联已有脚步声；应用蓝图后关闭旧脚步声循环，改用动画到音效的连线，支持开始、指定帧和间隔重复，避免重复播放。音画仍分别生成后手动关联，不做多要求自动分析。

## 验证

实际Godot4.6完成插件启用、六类场景导入／实例化，平面移动、左右镜像、四向动画、脚步声启停、平台落地／跳跃、奔跑加速、攻击信号和受击／死亡播放；在真实编辑器中验证键位更改、撤销／重做与资源保存后重载。Qt验证选帧弹窗的子导出窗口可用、资源真实写入、拖放文件路径、原素材Alpha保留、独立模式和插件安装备份。

自动验证覆盖Godot拖放数据及资源实例化；跨应用鼠标拖动手势未由自动鼠标测试覆盖。生成质量、动作对齐和像素画风仍由模型与输入决定。本轮Godot动作测试使用标记清楚的测试帧与音频，不冒充新增十五种动作的GPU生成质量验收。

新版整局工作台：游戏41类模块、角色10类模块，支持通用2D、类型化黑板、状态机、生命值、场景／信号与可复用子图；0.5第一阶段增加统一资源槽、独立预览、参数折叠和界面按钮。见 [蓝图技术文档](GODOT_BLUEPRINT_TECHNICAL.md)、[全部模块与参数](GODOT_BLUEPRINT_CATALOG.md) 和 [0.5阶段文档](BLUEPRINT_05_PLAN.md)。旧0.3／0.4自含游戏请创建新名称场景升级，安装插件不会覆盖原运行脚本。
