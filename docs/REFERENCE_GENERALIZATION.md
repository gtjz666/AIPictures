# 参考图优化的泛化验收与当前结论

2026-11-12。用户要求改进适用于不同素材，不能只修好现有测试角色。这是发布要求，不是已达到的能力声明。

## 当前发布决定

本轮姿势候选**不启用到普通软件**。正式流程仍使用已有主体提取、深度和训练结构适配器；它本身也存在体型迁移、接触、遮挡和额外肢体问题，不能宣传为精准换皮。透明帧导出单独完成，与姿势候选无依赖。

早期按角色类别配对选择路线的候选已从研究运行代码移除。后续候选只比较逐图估计的连接布局、头身连接、足式支撑和明显部位比例冲突；结构兼容时使用深度，冲突时尝试目标单图加具体动作文字。未知或无法适配时拒绝整理。这个方法的规则不依赖角色名字、颜色、文件名或特定动作，但**规则通用不等于输出质量通过**。

## 已完成的真实检查

以下四组实际运行了Qt两按钮流程、本地文字模型和图片模型，保留原始要求、中文稿／英文稿、输入SHA、工作流、唯一任务ID和输出。每组仅一个种子，人工复核非盲；素材曾用于此前研究，**不是独立留出测试集**。

| 来源与目标 | 实际路线 | 观察 | 结论 |
| --- | --- | --- | --- |
| 圆润卡通姿势→动漫人物 | 目标单图＋动作文字 | 两手抱头和惊讶大体实现，人物比例较早期深度方案好；身份细节有变化 | 局部改善，不足以发布 |
| 人体灰模→真实照片 | 深度＋主体图 | 大体保留低蹲，手脚与接触仍非精确 | 保留回归证据，不代表通用精度 |
| 圆润卡通→另一圆润生物 | 深度＋主体图 | 新增抬起手臂，同时保留原下垂手臂，形成四臂 | 拒绝 |
| 人物姿势→无发圆润生物 | 目标单图＋动作文字 | 自动稿写入“抓着头发”，结果给原本无发的目标添加头发 | 拒绝 |

前面的多种子探索还发现：增强完整来源深度可能把来源体型带入目标；增加来源RGB可能引入其颜色、衣物或轮廓；具体文字编辑有时更好，但仍会丢失身份细节。这些都是实测现象，不据此断言所有深度或多图模型无效。没有为失败样例继续增加名字、物种或动作专用分支，也没有选取成功种子替换失败结果。

离线协议检查通过不能代替上述视觉验收。研究候选最后一次全量为613通过、11个子测试通过、1个关闭超时失败；推理停止后该关闭检查单独通过。该候选仍因视觉失败不发布，不能将单项复测说成整套全绿。

实际素材、图片、模型和研究补丁保留在本机验收目录，不上传Git。交接记录给出本机路径；公共仓库只保存结论与方法。

## 后续任何候选必须满足的条件

1. **按用户用途分工。** 身份、姿势／表情、画风、构图和场景分别记录；没有要求迁移的来源属性不得自动成为目标属性。保留用户原话和可编辑稿，实际送入模型的图与文字必须可核对。
2. **不假定统一人体。** 按目标实际部件、连接、数量和比例检查可适配性，包含非人形、无脸／无肢体或机械物体。未知、遮挡或没有对应部件不能靠猜测补全。结构估计也需要验证，不能把模型枚举视作真值。
3. **按明确要求判断保留项。** 若用户要求新增部件或改变比例，相应变化是合法编辑；未要求时才检查额外／丢失部件与外观污染。不能用固定“两只手”等人体模板排除合法游戏角色。
4. **调试集与留出集分开。** 调参前冻结输入、原始要求、种子、分辨率、模型及配置。留出集包含不同对象、体型、画法、正反方向迁移、遮挡与接触、多个主体及不适用场景；不在留出素材上反复改规则后仍称留出验收。
5. **成对比较并保留失败。** 基线与候选使用同输入、同种子和同画布，预定多种子；分别观察动作／接触、身份与画风、部件数量、背景与用户要求服从性及耗时，不以单一相似度或几张成功图代替结论。
6. **明确适用范围再发布。** 出现新增肢体、来源外观污染、静默丢图或忽略要求时不得称为通用修复。新模型或控制方案先单独验收；不静默降级，也不以更长提示词掩盖模型不能完成的编辑。

这些是后续实验与发布门槛，尚未实现任意对象的部件真值、自动可靠质量判定或所有素材均准确的生成。当前不恢复普通动画动作分析、时间轴或未通过的视频姿态控制。
