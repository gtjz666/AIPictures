# 多图参考要求

在右侧「单张图片」页拖入1–4张静态图片。拖到左侧画布可按顺序添加，拖到某个编号卡片则替换该图。点击空卡片也可选图，悬停右上角×移除。编号保持稳定，移除图2不会把图3改成图2。参考预览不覆盖左侧成品。参考动画已移到「动画」页顶部，单张图片页不再混排动作素材。

参考区仅保留一个「参考要求」输入框、「生成提示词」按钮和「查看／编辑提示词」入口，不显示分析或回复区域。在输入框填写当前需求，例如：

> 保留图1的人物和服装，采用图2的姿势，融合图3和图4的画风。只画一个人物。

点击「生成提示词」或在输入框按Ctrl+Enter，只进行图片观察和需求整理，不自动开始生成。助手会逐张观察主体、外观、画法和静态姿势/构图，再按用户指定的分工编写中文正、反提示词；用途有冲突或不明确时仅显示简短补充提示。提示词不再占用右侧标签，点击「查看／编辑提示词」弹窗即可查看和手动修改，再点击顶部「生成」。

**中文显示，英文提交。** 同一次整理会在逐图观察之后，复用同一个已加载的识别会话再产出英文生成词（纯文本，不重新读图）。界面和弹窗始终显示中文；提交 Z-Image、FLUX 或多图参考时使用对应的英文。手动修改中文后，点击生成只对修改后的文字做一次纯文本转换，再提交；转换期间再次修改会丢弃旧结果。空反向词保持空，不在提交时擅自增加。若英文转换失败，中文提示词仍保留，提交前会报出明确原因，不会静默用中文或旧英文提交。

多图反向词由本次需求和用户原文生成，不再沿用“用户没填就留空”的旧逻辑。提示词不再混入“不增加限制”“没有问题”等整理过程说明。

手动修改的提示词不会在点击生成时再次被整理。再次整理时，新填写的要求优先；没有新要求时尊重手动编辑，不使用隐藏对话历史影响结果。识别期间修改需求会使旧结果失效。添加图片本身不调用识别模型。软件不读取动画内容、不生成自动动作时间轴。

当前多图组合用于本地单张图片。动画保持原有一张角色图＋动作素材路线；存在图2–图4时，动画整理/生成会说明限制，避免悄悄忽略素材。可先生成静态角色替换图，再主动将成品用于动画。PNG帧文件夹及动画模式下的帧序列导入不改；单张图片模式的多张PNG现在默认作为多图参考。

没有删除任何模型文件或工作流；本轮只调整软件流程，历史权重仍可复用。

## 实际输入与保存

图片不仅用于生成文字：生成工作流通过独立ReferenceLatent条件传入全部参与图片，输出仍从新潜变量开始。界面编号与模型图像顺序在提交时一次性转换；助手可建议参考顺序，但不会改变界面图号。缺少被引用图片、超出4张、选择不支持的路线时，在提交前报错，不用第一张图片代替所有参考。

每个任务保存原始可见提示词、编号、图片SHA、真实上传节点、模型输入顺序和完整工作流。有对应助手结果时保存逐图观察与计划。素材上传或更改不改变已经提交任务的冻结输入。普通单图自动路线仍为无参考Z-Image、有参考FLUX，手动引擎选择不暗中改动；多图明确要求自动或FLUX，本轮未接入云端多图。

依据：[BFL官方多图编辑说明](https://docs.bfl.ai/flux_2/flux2_image_editing)、[官方FLUX.2代码与模型能力表](https://github.com/black-forest-labs/flux2)。参考属性分工是模型的语义条件，不能承诺像素级姿态、身份或风格隔离。
