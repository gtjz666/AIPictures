# 动作说明与长动画

参考图和参考动画统一在右侧「参考」页，上半图片、下半动作预览，可调整两块高度。悬停右上角×移除对应素材；参考动画有独立的播放/暂停和定位滑条。左侧棋盘只显示生成结果，参考播放和源起点定位均不改变成品播放器、导出内容或生成种子。播放/暂停统一使用经典三角和双竖线图标。

动画页顶部为「制作类型」，替代动作模板；当前开放动画素材，长视频未完成整段验证，暂不可选。操作区右侧只有「分析动作」，左侧依次为循环和起点滑条，滑动即联动预览。视频/GIF按秒定位，PNG序列显示起始帧编号；PNG的FPS可调整。导入、切换预览和点击生成均不会自动调用识别。

可直接拖入PNG帧文件夹：按帧编号自然排序（1、2、10），读取source/sequence/sprite_sheet/video JSON里的FPS，缺省24 FPS；有效帧清单可引用文件夹内的子目录，否则仅扫描当前层PNG。上限1500张、整组2GB。导入后直接预览，不经过源视频解码。调整FPS会创建新素材副本，保持原文件及已入队任务不变。

点击「分析动作」后，下方显示可编辑的开始时间、结束时间和目标动作。双击单元格修改，长内容可滚动。修改会同步到正向提示词并冻结到生成任务；时间无效、倒序或重叠时不能入队。有动作素材时使用参考素材原始秒数；输出时长和「循环参考动作」不会把原始时序拉伸。没有动作素材时，时间对应输出动画，修改输出时长会同比调整动作表。原始素材不改写。

PNG素材自动显示「动作说明 / 帧内容」选项，视频/GIF只显示动作说明。在动作说明中点击「分析动作」会整理正反提示词和可编辑时序；在帧内容中点击同一按钮只观察当前选中的PNG帧，不推测整段运动，也不覆盖已有生成提示词。帧内容表可点击回看对应源帧。

正向提示词只保留整体外观/动作意图和下方一份详细时序；识别器不再被要求同时输出两份时间轴，旧版“从0秒开始：…”摘要也会整理。动作表修改同步更新详细时序，保留用户另加的风格要求。反向词保留用户原文。单帧描述、左右方向和遮挡仍可能误判，模糊图尤其需要核对；观察源帧不等于精确重建其运动。识别进程退出后再允许图像生成。

[连续动作观察](TEMPORAL_MOTION_REVIEW.md)现在使用最多64个源时间观察点和重叠图组；程序拼接完整源区间，避免全局规划漏掉末段。纯色背景下补充可验证的脚部相对高度，不能区分的动态细节标黄待核对。该处理不修改源素材或输出原色，也不保证逐帧动作准确。播放区域隐藏或窗口最小化时会暂停，以减少后台绘制。

## 时长与续接

当前界面仅开放2–8秒动画素材生成；较长参考素材仍可选择片段。超过8秒的未完成历史任务不能从记录继续，已完成成片仍可播放和导出。长视频分段的程序检查和单段实测不能视为整条长片画质验收，因此暂不开放。

以下是保留的研究实现，不代表当前主界面可用：video_chain.py串行短段，每段最多192帧（含引导和长度对齐开销），输出总时长保护上限2小时。

- 无动作素材：沿用原H3图/文字路线，后续段的首帧取上一段最后使用的原生RGB帧，不重复缩小安全画布。
- 有动作素材：沿用专用Ref2VA模型和原角色参考，逐段推进参考起点，启用循环时按原素材时长取模；不循环且超出参考时保持最后可见姿势。使用官方`MiniMaxH3AddGuide`把上一段末帧约束在新段第0帧。编码条件完整落盘、编码进程退出后才启动采样，保留Windows逐张量读取器。
- 后续段略去一个首帧引导位置，裁掉长度网格对齐的尾部多余帧，使合成结果达到请求帧数（向上取整到1/24秒）。不做插帧、交叉淡化、历史帧混合或自动抗锯齿。
- `segments/`保存尝试，`chain.json`保存计划、种子、SHA和接缝指标。研究工具支持显式继续未完成段，OS锁防重复启动；普通记录入口不开放未验证长片继续。
- 最终主动画采用无损RGB编码，仍可完整循环播放、自主勾选帧、导出PNG/精灵图。大精灵图仍受尺寸保护，过大时使用独立PNG。

首帧约束只能帮助衔接，不等于使用整段运动历史。接缝附近可能出现速度、姿态、构图或颜色偏差；记录平均RGB差异并给出警告，不以混帧掩盖。相邻RGB变化指标也不是运动质量证明。较短的旧任务继续保留原先模型对齐后的实际时长。

官方依据：[MiniMax H3模型说明](https://github.com/MiniMax-AI/MiniMax-H3/blob/main/README.md)、[ComfyUI官方H3节点](https://github.com/Comfy-Org/ComfyUI/blob/master/comfy_extras/nodes_minimax_h3.py)。参考源码用于核对接口，不改原Comfy核心或安装未验证的新模型。

## 验证入口

```powershell
python -m pytest -q tests/test_video_chain.py tests/test_animation_editor.py tests/test_local_intent.py
python -m tools.verify_animation_editor
```

`tools.probe_continuation`为真实GPU验收：读取已完成动画的末帧，只生成一段新的续接，不重跑父动画。使用新的输出目录；该检查耗时较长。合成帧测试只证明分段、恢复、时序和逐像素回读；不能宣称真实长动画已经无缝或识别100%准确。真实检查的路径、完成状态、目视结果单独写入本机交接。
