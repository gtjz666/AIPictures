# 带配乐短视频

> 以下保留2026-11-10早期短视频实现记录。当前入口已统一为「长视频 / 精灵图 / 音频」，视频默认H3原生配乐，独立音乐使用专用模型；当前操作与验收以[长视频和音频说明](LONG_VIDEO_AUDIO.md)为准。旧的合成旋律仅为历史任务兼容，不是新视频默认路线。

在顶部选择「动画」，右侧「制作类型」选择「短视频（含配乐）」。当前支持2–8秒；长视频入口保留为不可用，后续单独验证分段衔接。

## 从要求到脚本

1. 填写「短视频要求」，可描述场景、情节、镜头运动和声音。
2. 选择舒缓旋律、轻快旋律或紧张氛围，也可以导入自己的音频。
3. 点击「生成脚本与提示词」（输入框中也支持Ctrl+Enter）。本地创作助手整理整体场景、镜头起止秒数、画面与动作、镜头、声音，以及中文正反提示词。
4. 「查看／修改脚本」可编辑镜头表；应用后更新提示词。「查看／编辑提示词」继续使用原来的可编辑提示词弹窗。手改提示词后，生成采用可见文字，不暗中恢复旧脚本。
5. 点击顶部「生成短视频」，完成后在左侧预览、播放、暂停和定位。

导入的配乐优先于自动旋律；重新选择自动配乐类型可恢复自动制作。再次整理时保留用户手写的排除项，不重复累积上次自动生成的反向词。更改要求后需要重新整理脚本，或明确手改提示词，避免无意中生成旧要求。

不配置创作助手时也可直接填写提示词或要求，软件按一个覆盖全片的镜头整理格式，不自动启动识别。脚本镜头须从0秒连续覆盖当前片长，不允许空缺、重叠或越界。已有脚本后修改片长，需要相应修改脚本或重新整理。表格是创作要求，不是对参考视频的自动识别结果，也不是硬关键帧控制。

短视频目前复用本机已经验证的H3引擎，不增加视频/音乐大模型。可用一张图片和一份动作参考；多张图片组合仍先生成单张成品，再用于动画。单张图片原有的中文显示、英文提交不变；H3仍采用已验证的中文提示词策略。

## 声音与导出

- 普通H3路线保留模型原生环境声/声音，再叠加配乐；专用动作参考路线没有原声音轨时仍添加配乐。
- 自动配乐是本地合成的原创器乐旋律，提供三种基础风格，不是新的AI作曲模型。精细配器、指定歌曲、歌词演唱等需导入已有音频。
- 音频短于成片时循环铺满，超出部分裁掉。混合后统一限制峰值，配乐为空或接近静音会报错，不将无声音轨标为成功。
- 原声、配乐、混合音轨和无声画面在任务目录分别保留。原始RGB和额外对齐帧保留，不插帧、混帧、提前抠图或改变角色尺寸。
- 「导出…」包含完整带声视频、仅画面、仅音频、音画分别导出，以及原有的动画帧／精灵图。拆帧仍只在用户选择后处理。
- 完整带声MP4由无声视频流原包复制并加入AAC音频；音画分离复制画面流，音频以48kHz立体声PCM WAV导出，不再次压缩画面。原有动画素材模式继续保持原来的RGB预览与自主导出流程。
- 预览以音频播放位置驱动画面定位；暂停、循环、拖动与关闭均同步处理声音。关闭播放器释放音频文件占用。

## 开发验证

`tests/test_short_video.py`覆盖真实CPU音画合成、分离、RGB逐像素保留、原声裁切、短配乐循环、脚本时长边界、取消保护以及原生Qt流程。`tools.verify_short_video_ui`使用明确标记的模型替身，但使用真实音频编码、播放时钟和导出。

`tools.verify_short_video_live`用于串行的真实本地助手/H3验收。已存在的视频/编码记录不会自动重跑；中断后先调查进程和已保存阶段。成功记录附生成参数、脚本、日志、音轨、PNG接触表和逐像素/音轨检查。流程通过不等于每次生成都严格遵从镜头或达到专业配乐质量。
