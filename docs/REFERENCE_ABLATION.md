# 静态参考控制对照实验

本轮先验证提示词与基座配置，不改变普通软件默认值。使用两个已完成任务的冻结工作流：复杂人物照片换低蹲姿势、非人形卡通换抱头姿势。结构深度、实际主体图、画布、适配器强度与采样器保持一致，图像文件 SHA 写入计划。旧成功任务只提供输入和自动成稿；私有后端重新生成基线，不把旧图片混作同环境对照。

## 提示词对照

每组在看结果前固定原种子、原种子加一、原种子加二，比较三种条件：

| 条件 | 改动 |
| --- | --- |
| auto | 完整现用固定操作规则与已有自动外观描述 |
| no_caption | 只删除自动描述后缀，固定操作规则不变 |
| short | 全部文字替换成简短姿态迁移与外观保留指令 |

`no_caption` 用于隔离自动描述的影响；`short` 同时改变固定规则与描述，只能评价整体文字策略。每次变换后恢复文字节点，验证整个图与原图完全相等，防止无意改变其他参数。没有重新调用识图模型，不据本轮耗时宣称识图速度改善。

每组另用原种子探索只含 `refcontrol`、完全空文本两种情况。空文本仍有图像条件与训练适配器，不代表纯粹无条件生成，也不代表任意编辑可以不提供操作指令。

## Base 配置对照

只在两组原种子比较：官方 Base FP8、20 步、CFG 5、独立空文本负条件；其余结构和主体输入与 `short` 相同，适配器强度 0.9。依据 [RefControl 模型与作者工作流](https://huggingface.co/thedeoxen/refcontrol-FLUX.2-klein-4B-reference-depth-lora/tree/0ae1ef7f9acc4e55ec2237360943c3c3032d3583)，而非把通用 Base 示例的另一组参数当作该作者设置。

这比较的是整套配置：基座、量化、步数与引导均有变化，不能把效果或速度归因于单个因素。每组一个种子也不足以证明稳定优于默认配置。

[官方 Base FP8](https://huggingface.co/black-forest-labs/FLUX.2-klein-base-4b-fp8/tree/103db268c10d4d3921101b46057671f9ac460da6) 固定版本下载后核验大小和 SHA；下载器不注册为默认或 validated。没有升级现有推理环境。

## 记录与复核

2026-11-11 已完成 24 张新图：18 张主要提示词对照、4 张极简／空文本探索、2 张 Base 配置；2026-11-12 完成归档复核。评分标准在出图前保存；人工检查整体姿势、外观保留、手脚接触和严重多肢／融合错误，不声称得到经过校准的准确率。复核不是盲评，没有独立评价者。

## 结果与决定

| 对照 | 人物照片低蹲 | 非人形卡通抱头 |
| --- | --- | --- |
| 只去掉自动描述 | 三个种子中一组手位改善、一组退步、一组接近；没有一致优势 | 大姿态保持；部分结果更柔和，但局部颜色位置和背景仍会漂移 |
| 简短操作指令 | 大姿态仍在，三张均迁入深背景／黑边，一张凭空增加凳子 | 抱头仍在，没有明确动作收益；局部颜色与背景问题仍在 |
| 只触发词／空文本 | 大姿态仍能形成；空文本一只脚灰白失真，黑边未消失 | 简单抱头仍成立，细节和比例没有被精确锁定 |
| Base FP8、20 步、CFG 5 | 大姿态保持；细节模糊、手脚接触和黑边未解决 | 大姿态保持；外观更灰淡，没有清楚的精度优势 |

`auto` 本身也有失败：照片第三个种子出现前臂／手部缺失。不能把当前方案已能生成大轮廓说成精准换皮。卡通的主要抱头动作在三种文字策略的三个种子均出现，但这不等于每个部位或任意对象都能精确迁移。

实际每张耗时如下。主要文字条件为各三张的中位数，Base 为各一张；包含加载、缓存状态差异和保存，不是纯采样性能基准。

| 素材 | auto | no_caption | short | Base short |
| --- | ---: | ---: | ---: | ---: |
| 人物照片，848×1024 | 48.36 秒 | 49.01 秒 | 57.52 秒 | 305.50 秒 |
| 非人形卡通，512×512 | 45.06 秒 | 44.53 秒 | 44.77 秒 | 224.97 秒 |

Base 与同一原种子、同一 `short` 的蒸馏配置相比，耗时分别约 5.31 倍、5.04 倍。这里只测试各一个种子和这一组文字，不能由此否定 Base 在其他提示词／参数下的潜力，也不能将差异单独归因于量化或步数。

决定：保持普通软件的现有模型、可见提示词与默认流程，不启用空文本或将 Base 注册为默认。实验支持图像结构条件能直接传递大姿态；没有支持仅靠删描述、缩短文字或套用本次 Base 配置即可稳定修复局部错误。结构估计、体型映射、遮挡和生成器服从性各自的影响仍未被分离，后续需针对这些环节验证。

本轮没有重跑语言识别、安装新骨骼／三维重建模型、验证视频或实现代码驱动的混合渲染，不把文字对照结果冒充这些路线的验收。

完整性复核通过：24 个新任务 ID 均唯一、所有图像尺寸正确、冻结输入 SHA 未变、实际工作流变化符合协议。前期共享后端在执行节点前的 CUDA 错误，以及私有工具启动等待的失败均单独保留，没有算入这 24 张成功结果。未重启共享后端或修改驱动。成功私有实验进程已关闭。

工具入口：

- `tools.install_klein_base_probe`：固定版本、校验文件、保留下载收据；不覆盖已有异常文件。
- `tools.probe_reference_isolated`：使用现有 Comfy 源码和环境启动自有进程；指定独立输入、输出、用户目录与数据库；退出只关闭自有进程。
- `tools.probe_reference_ablation`：冻结输入、串行提交、保存工作流与 prompt ID；仅恢复已知任务，不自动重投失败或未知状态。
- `tools.review_reference_ablation`：生成带条件／种子标签的 PNG 对照，原图不变。

运行私有工具需要显式提供 `--comfy-source`、`--model-paths-config`、`--input-root`、全新 `--session` 与已完成的 `--cases`。它不会安装依赖、启动浏览器或重启共享服务。只有确认没有其他生成工作、现有资源可用时才开始。

本机数据、模型、原始参考和生成图不入 Git；实际运行状态、失败尝试与结果路径放在忽略的本机交接记录。成功实验早期调用未显式指定数据库 URL，遇到共享数据库锁后以数据库功能不可用继续；归档保留实际命令，最终工具对后续运行显式指定独立数据库。该启动设置修正不作为图像质量改进的证据。
