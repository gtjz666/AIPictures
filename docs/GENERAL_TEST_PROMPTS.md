# 中文通用测试正反词

以下是可手动复制的测试例子，**不会自动预填或覆盖界面**。先选生成类型；人物换视角用单张“按描述创作”，参考强度建议先试 0.4–0.65。动画由类型选择加入实际动作条件，不要求文字里出现“动画”。风格 LoRA 必须手选。

单张 SDXL 的中文转换仍是有限词表，未知中文会保留而不会删除；这不等于完整中文理解。改变风格、构图与参考一致性之间存在取舍；下列提示不保证消除模型错误。

## 单张：侧视参考改正面

正向：
```text
参考图中的同一个人物，正面全身，面向镜头，自然站立，双臂自然下垂，双脚完整入镜。保持参考图中的角色身份，保持发型，保持服装，保持原有配色。人物居中，轮廓清晰，纯色背景。
```
反向：
```text
侧视图，背面，三视图，人物设定图，多个人物，重复人物，多余肢体，多余手臂，多余腿，多余手指，肢体缺失，头部裁切，脚部裁切，服装变化，颜色缺失，曝光过度，重影，模糊，文字，水印
```

## 单张：坐姿与三分之四视角

正向：
```text
参考图中的同一个人物，四分之三视角，坐在木椅上，身体放松，双手放在膝盖上，完整身体与椅子入镜。保持参考图中的角色身份，保持发型，保持服装，保持原有配色，柔和均匀光照。
```
反向：
```text
站立，侧面站姿，多视图，重复人物，多余椅子，手脚粘连，多余肢体，穿模，身体比例错误，颜色突变，过曝，运动模糊，文字，水印
```

## 单张：背面角色

正向：
```text
参考图中的同一个人物，背面视图，全身，自然站立，镜头平视，双脚完整入镜。保持发型长度、服装结构与原有配色，背部服装完整，均匀光照，简单背景。
```
反向：
```text
正面，正脸，侧脸，回头，多人物，三视图，多余肢体，服装颜色变化，头部裁切，脚部裁切，模糊，文字，水印
```

## 单张：游戏物件

正向：
```text
游戏道具，单个金属宝箱，等距视角，木质箱体，深色金属包边，正面金色锁扣，箱盖闭合，完整物件居中，手绘，轮廓清晰，简单背景。
```
反向：
```text
人物，手，多个宝箱，重复物件，物体裁切，透视错误，箱盖破损，文字，商标，水印，模糊，曝光过度
```
需要透明道具时选择“透明主体”；画面背景不会靠“透明”提示词自动生成 alpha。

## 单张：完整场景背景

正向：
```text
背景场景，森林中的石桥与溪流，黄昏，远景，镜头平视，暖色灯光，完整环境构图，无人，手绘，清晰的前景、中景和远景，适合横版游戏的场景背景。
```
反向：
```text
人物，角色立绘，孤立物件，透明背景，画面分格，重复建筑，错误透视，模糊，过曝，文字，水印
```
选择“完整画面（保留背景）”；不要对场景启用透明主体分割。画布可选 1024×768。

## 动画：已有角色参考图走路

界面选“动画序列帧 / 走路 / 参考图”，正向可留空。需要明确测试要求时：
```text
保持参考图中的同一个角色，保持发型、服装、配色与身体比例。固定镜头，完整身体与双脚入镜，原地运动，动作自然连贯，上身轻微起伏，左右腿交替，手臂反向摆动，首尾自然衔接。
```
反向：
```text
身份变化，发型变化，换装，发色变化，颜色缺失，过曝，多余肢体，重复脚掌，重复鞋尖，手脚粘连，双脚同相运动，滑步，重影，运动模糊，镜头移动，缩放，人物出框，背景残留，文字，水印
```

## 动画：纯文字角色

界面选“动画序列帧 / 待机（也可改走路）/ 仅文字描述”：
```text
一个成年女性冒险者，短发，绿色短外套，米色衬衫，深色长裤，棕色皮靴，全身，右侧视图，面朝右方，清晰手绘游戏角色，服装结构简洁，均匀光照。
```
反向：
```text
多个人物，角色设定图，三视图，多视图，重复人物，服装变化，颜色突变，缺少肢体，多余肢体，重复脚掌，重影，模糊，头脚裁切，文字，水印
```

完成后先逐帧检查身份、衣服、手脚与首尾，再选择普通导出或像素素材导出。像素捕捉/调色板对齐不能修正 AI 画错的身体结构。
