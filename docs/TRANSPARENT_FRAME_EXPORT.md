# 导出透明精灵图

1. 在动画播放器点击「选帧与导出精灵图…」打开选帧窗口。勾选一帧即加入下方缩略图条，所选帧按导出顺序和当前 FPS 自动预览。点击缩略图可以暂停并查看单帧。循环由「循环播放」控制。
2. 「透明背景」默认勾选。点「导出精灵图…」后，AlI 才对选中的帧去背景。保存结果为一张 PNG 和同名 JSON，把两者放在一起，再将 PNG 拖到 Godot 场景蓝图的动画轴。
3. 导出弹窗显示当前步骤和「取消导出」。主窗口左下方的导出任务条显示百分比，达到 100% 表示文件已写完。导出期间可以继续提交和查看生成任务。

原画面、尺寸和 RGB 保留，透明化只改变 Alpha。精灵图每个切片和对应导出帧逐像素一致。关闭选帧窗口后可从导出弹窗继续查看步骤或取消任务。重新打开选帧窗口时只读取原始画面。缓存清理会保护导出任务正使用的素材。

验证入口为 `tools.verify_transparent_export`，使用已有 RGB 图像验收只处理所选帧、透明 PNG 与精灵图回读、原背景导出和源画面完整性。
