# 在导出时准备透明动画帧

1. 在动画播放器点击「导出… → 动画帧／精灵图…」打开选帧窗口，直接查看原画面。播放完整动画、播放选中帧或拖动滑块定位，再勾选要用的帧。
2. 「透明背景」默认勾选。点「导出所选 PNG…」「导出精灵图…」或准备拖入 Godot 后，AlI 才对选中的帧去背景。若希望导出完整画面，取消勾选。
3. 导出时会弹出可取消的进度窗口，左下方也有独立的导出任务条。此时可以继续提交和查看生成任务。100% 表示导出文件已写完。

原画面、尺寸和 RGB 保留，透明化只改变 Alpha。精灵图每个切片和对应导出帧逐像素一致。关闭选帧窗口后可从导出进度窗口继续查看或取消任务。重新打开选帧窗口时只读取原始画面。缓存清理会保护导出任务正使用的素材。

验证入口为 `tools.verify_transparent_export`，使用已有 RGB 图像验收只处理所选帧、透明 PNG 与精灵图回读、原背景导出和源画面完整性。
