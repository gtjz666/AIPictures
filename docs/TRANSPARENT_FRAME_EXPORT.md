# 导出 PNG 序列和精灵图

1. 在动画播放器点击「选帧与导出…」打开选帧窗口。勾选一帧即加入下方缩略图条，所选帧按导出顺序和当前 FPS 自动预览。点击缩略图可以暂停并查看单帧。循环由「循环播放」控制。
2. 「透明背景」默认勾选。确认导出时，AlI 为选中的帧去背景。
3. 选择一种输出格式。

   - 「导出 PNG 序列…」在所选位置新建文件夹，按源帧顺序保存 `frame_000.png`、`frame_001.png` 等。另存的 `animation.json` 记录顺序、FPS 和循环。将整个文件夹拖到 Godot 动画轴即可读取。
   - 「导出精灵图…」保存一张 PNG 和同名 JSON。将两者放在一起，再把 PNG 拖到 Godot 动画轴即可切帧。
4. 主窗口左下方的导出任务条显示百分比和「取消导出」。鼠标停在任务名称上可查看当前步骤。达到 100% 表示文件已写完。导出期间可以继续提交和查看生成任务。

原画面、尺寸和 RGB 保留，透明化只改变 Alpha。精灵图每个切片和对应导出帧逐像素一致。关闭选帧窗口后可从主窗口的导出任务条继续查看进度或取消任务。重新打开选帧窗口时只读取原始画面。缓存清理会保护导出任务正使用的素材。

验证入口为 `tools.verify_transparent_export`，使用已有 RGB 图像验收只处理所选帧、透明 PNG 与精灵图回读、原背景导出和源画面完整性。
