# 在导出时准备透明动画帧

播放预览保留完整画面，不在生成结束时额外拆帧或去背景。点击「动画帧／精灵图」或「选帧导出」后，先从原生RGB准备PNG，再用现有本地CPU去背景模型生成透明副本；完成后才显示选帧窗口。期间有进度，可取消；不重新生成动画。

原RGB帧、原生颜色数组和完整视频保留，透明副本不改变画布、裁切、缩放、RGB或帧顺序，只改变Alpha。选帧窗口默认显示已处理的透明版本；取消「透明背景」即可查看并导出保留原背景的版本。精灵图切片与所选PNG逐像素一致，不进行时间混合。

重复打开按源清单SHA、每帧SHA、模型SHA和处理版本校验缓存，不再次加载模型。失效、失败或取消不覆盖原动画，也不打开半完成的选帧窗口。CPU模型在自有子进程中运行，完成或取消后退出；缓存清理会保护导出准备与选帧窗口所用的原任务。

实际验收使用两张已真实生成的RGB图组成延迟拆帧输入：真实本地BiRefNet、真实Qt导出入口，确认窗口显示前已有Alpha、透明／原背景两种导出、原RGB／尺寸不变、精灵图切片回读一致，以及第二次打开不启动处理进程。这是导出流程验收，不是新的视频生成质量试验。见 `tools.verify_transparent_export`。
