# 横版跳跃、基础攻击、动作描述与动画换风格

## 使用

运行 `run.bat`，在“角色与生成…”中选择“动画序列帧”。已有图片通过“＋ 参考图”导入，角色来源选参考图；没有图片则选择文字来源并描述角色外观。正向/反向区保持用户内容，不会重新预填模板。所选动画类型决定动作。

- **横版跳跃**：短促起跳、前后错开的手臂与双腿、上升收腿、顶点、下落伸腿、落地缓冲。PNG 不烘焙整体跳跃高度，适合由游戏物理控制角色坐标。播放栏可开启“游戏位移预览”，仅平移已生成帧；另附 `jump_game_preview.gif` 演示，不能将这个轨迹当作模型自身输出。
- **基础攻击**：单次徒手向前出拳，含蓄力、出拳、短暂停顿、收招和站立终点。不会自动添加武器、敌人或攻击特效。`game_animation.json` 提供 `startup / active / recovery` 帧下标；下标从 0 开始，是美术阶段标记，不会自动生成碰撞框。
- **自定义动作 → 骨骼编排**：例如“下蹲，然后出拳”或“走路1秒，然后跳跃1秒”。支持走路、待机、跑步、跳跃、下蹲、出拳的顺序组合，最多 6 段。秒数控制各段比例；最终总时长由导出帧数 ÷ FPS 决定。描述会显示识别顺序，未知动作明确报错；可先查看/调整对应完整骨骼。多段推荐 16 帧，过多动作压入 8 帧会丢失细节。
- **自定义动作 → AI 自由动作（实验性）**：任意动作说明直接输入现有 Wan2.2 I2V 高/低噪模型，不经过走路意图转换，不强制人体骨骼，不裁掉片段后半段来寻找循环。不支持手动逐帧骨骼，默认一次播放。复杂转身、接触、翻滚等是否成功必须检查，不能承诺任意中文描述准确实现。

骨骼编排不解析速度变化、重复次数和同时执行两个动作，这类说明会提示切换自由模式，不会识别后静默忽略。各段骨骼会在连接处回到基准姿势，不是任意动作之间的连续过渡模型。

8/16 帧仍来自原生连续采样，没有时间混合。跳跃、下蹲、攻击、编排和自由动作保留片段终点，一次播放后可重播；走路、待机、跑步循环。新骨骼版本为 4；旧版已保存动画不重生成。旧的未编辑预设进入编辑或新建任务时升级，已有手动编辑保留；点“恢复自动周期”才重建。

## 参考图与风格选择

默认不勾选“按手动选择的 LoRA 改变参考画风”，参考图直接作为外观基准；风格列表中的旧选择不暗中生效。没有自动分析提示词或选择 LoRA。

需要改画风时勾选该项，再点“选择风格类型 / LoRA…”，主动选择 SDXL 风格模型及强度，“模型与画面…”选择 SDXL 基础模型。流程先用原图、IP-Adapter、SDXL 图生图和所选 LoRA 生成风格基准，再用 Wan 生成动作。SDXL LoRA 不连接 Wan 模型。生成前仅合成已有透明通道，没有先对基准图分割去色；动画帧生成完成后再去背景。

换风格优先呈现 LoRA 的风格，可能改变颜色、线稿和衣物细节；不勾选时维持参考最小修改路线，仍不能保证逐像素相同。原图保留，另存 `style-anchor/source_rgb.png`、风格结果、实际工作流和来源校验值。风格基准生成后重新自动适配骨骼；要手动编辑，应先将风格图作为新参考导入。

## 输出与检查

“导出动画…”的 ZIP 包含 PNG、精灵图、GIF 和 `animation.json`。跳跃/攻击新增 `game_animation.json`，跳跃另包含位移演示 GIF。游戏枢轴为画布 `(384,978)`，以左上角为原点；这是约定坐标，不是检测出来的每帧碰撞脚底。生成仍可能存在轻微位置漂移和细节变化。

GIF 仅支持有限色和二值透明，8 FPS 的帧时长以 120/130 ms 交替近似，整秒时长保持正确。PNG 不受 GIF 量化或演示位移影响。像素导出仍由独立 `sprite_pipeline` 完成；没有增加全局抗锯齿、混帧或自动超分。

## 可重复测试

```powershell
python -m pytest -q
$env:QT_QPA_PLATFORM='offscreen'
python -m tests.live_platformer_controls
python -m tests.live_animation_modes
# 以下会实际生成，耗时较长；每次用新目录。
python -m tools.verify_animation_modes --reference '参考图.png' --out data/platformer-test --actions jump attack
python -m tools.verify_style_anchor --reference '参考图.png' --out data/style-anchor-test
```

自动测试覆盖稠密骨长与支撑脚、跳跃固定根部/非对称姿势、攻击伸展和收招、编排序列及未知指令、LoRA 实际图连接、自定义 I2V 原文保留、完整片段选帧、透明导出、GIF 时长、游戏元数据与不改 PNG 的位移预览；Qt 测试覆盖实际控件到后台参数绑定。模拟后端测试不能替代视觉验收。

实际本机测试记录放在 `data/platformer-acceptance/20261031_native`，模型和生成文件不提交 Git。新增动作的视觉评估另记在同目录，不能用流程成功率代替肢体/配色正确率。
